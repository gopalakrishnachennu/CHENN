# ResumeOS corporate UI audit

## Issues identified and corrected

1. Job form was too narrow for desktop and created excessive vertical scrolling.
2. Candidate form used the same tall mobile-like layout on large screens.
3. Repeated large rounded cards made the portal look consumer-oriented rather than corporate.
4. Page margins and section padding left too much unused workspace.
5. Admin sidebar and header consumed more width and height than necessary.
6. Form controls were taller and rounder than an operations console needs.
7. Job-description and skill fields did not use the available horizontal space.
8. Tables used loose row spacing, reducing the number of visible records.
9. Several secondary labels were too small for comfortable operational use.
10. Candidate pages were restricted to a narrow content column on wide screens.
11. Dialog sizes were inconsistent between candidates, jobs, prompts, and resumes.
12. The overall geometry lacked one shared enterprise design system.

## Corporate system applied

- Four-column job form on desktop, two columns on tablets, one column on mobile.
- Three-column candidate profile form on desktop.
- Wider desktop dialogs with sticky, compact action areas and internal scrolling.
- Six-pixel primary corner radius and four-pixel controls.
- Denser cards, tables, page spacing, sidebar, and header.
- Wider candidate and admin workspaces.
- Minimum readable metadata sizing increased.
- Existing color and font customization remains active across both portals.
